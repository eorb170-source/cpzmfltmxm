# 업무 체크리스트

여러 업무 점검을 데일리/위클리/먼슬리/연간 주기로 관리하고, 예정 시간이 지나도 체크되지 않은 업무는 데스크톱 알림으로 알려주는 로컬 데스크톱 앱입니다. 완료 이력을 기간별로 집계해 연봉협상 자료(PDF)로 바로 내보낼 수 있습니다.

## 주요 기능

- **오늘의 체크리스트**: 데일리/위클리/먼슬리/연간/단발성 업무를 주기별로 구분해 오늘 해야 할 항목만 보여줍니다.
- **반복 업무 관리**: 업무마다 반복 유형(매일 / 매주 특정 요일 / 매월 특정 일자 / 매년 특정 날짜 / 1회성)과 분류(카테고리)를 지정할 수 있습니다.
- **예정 시간 + 미체크 알림**: 업무에 예정 시간을 설정하면, 그 시간이 지나도 체크가 안 되어 있을 경우 설정한 간격으로 반복해서 데스크톱 알림을 보냅니다.
- **이력 조회**: 기간/상태(완료·대기·미완료)별로 지난 수행 기록을 조회합니다.
- **연봉협상 자료**: 기간을 선택하면 분류별·업무별 완료 횟수를 집계해 표로 보여주고, 그대로 PDF 파일로 저장할 수 있습니다.
- **데이터 저장**: 브라우저 저장소가 아닌 로컬 SQLite DB 파일(사용자 데이터 폴더)에 저장되어, 앱을 껐다 켜도 안전하게 유지됩니다. (`sql.js` 기반이라 Visual Studio Build Tools 같은 별도 컴파일 도구 없이 `npm install`만으로 설치됩니다.)

## 실행 방법

```bash
npm install
npm start
```

## 배포용 패키징 (설치 파일 생성)

```bash
npm run dist
```

`electron-builder` 설정에 따라 `dist/` 폴더에 OS별 설치 파일이 생성됩니다(현재 설정: Windows nsis / macOS dmg / Linux AppImage).

## 폴더 구조

```
electron/
  main.js        # 앱 진입점, IPC 핸들러, 창 생성
  preload.js     # 렌더러에 안전하게 노출되는 API
  db.js          # SQLite 스키마 및 초기화
  scheduler.js   # 반복 업무 인스턴스 생성 + 미체크 알림 로직
  reports.js     # 연봉협상 자료(집계/HTML/PDF) 생성 로직
  dateUtils.js   # 날짜/반복 규칙 계산 유틸
renderer/
  index.html     # 화면 구조 (탭: 오늘/업무 관리/이력/연봉협상 자료/설정)
  app.js         # 화면 로직
  styles.css     # 스타일
```

## 데이터 모델 요약

- `tasks`: 업무 템플릿(제목, 분류, 반복 유형/설정, 예정 시간, 알림 사용 여부·간격)
- `task_instances`: 특정 날짜에 실제로 발생한 업무 건(완료 여부, 완료 시각, 알림 발송 이력)
- `settings`: 전역 알림 on/off, 기본 알림 간격 등

앱이 켜져 있는 동안 1분마다 다음을 수행합니다.
1. 날짜가 바뀌면 지난 날의 미체크 항목을 "미완료(경과)"로 표시하고, 오늘 날짜에 해당하는 반복 업무 인스턴스를 새로 생성합니다.
2. 예정 시간이 지났는데 아직 체크되지 않은 업무가 있으면(알림이 켜져 있는 경우) 데스크톱 알림을 보냅니다. 이후에도 체크되지 않으면 업무별로 설정한 간격마다 다시 알립니다.

## 추가로 고려해볼 만한 아이디어

앱을 쓰면서 필요해지면 추가로 요청해 주세요. 예를 들어:
- 특정 업무를 완료할 때마다 성과/메모를 남기고, 연봉협상 자료에 하이라이트로 포함하기
- 업무 항목에 우선순위나 소요 시간을 기록해 통계 내기
- 여러 대의 PC/모바일에서 데이터를 동기화하기(현재는 이 PC의 로컬 DB에만 저장됩니다)
- 완료율이 낮은 반복 업무를 자동으로 강조 표시하기
